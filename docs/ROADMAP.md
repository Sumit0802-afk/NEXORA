# Roadmap

## Phase 1 — Foundation (weeks 1–2)
- Requirements, flows and design system
- Authentication and project creation
- Canonical design schema
- CI/CD and local development

## Phase 2 — 2D editor (weeks 3–6)
- Grid, zoom, pan and selection
- Room/wall drawing and dimensions
- Doors/windows, snapping, undo/redo
- Geometry validation and save/load

## Phase 3 — smart generation (weeks 7–10)
- Natural-language requirement parsing
- Rule-based candidate generation
- Constraint validation and scoring
- Regeneration and user approval

## Phase 4 — 3D (weeks 11–13)
- Derive walls/floors from canonical data
- Openings, furniture and materials
- Camera presets and 2D/3D synchronization

## Phase 5 — Beta (weeks 14–16)
- PDF/PNG export, versions and sharing
- Autosave recovery and background jobs
- Usage quotas and basic billing

## Phase 6 — Launch readiness (weeks 17–20)
- Geometry and smart evaluation suite
- Security and load testing
- Monitoring, backups and restore drills
- Closed beta and fixes

Timing is an estimate for a focused team, not a guarantee.
